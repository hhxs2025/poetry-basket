# poetry-basket

#### 介绍
诗篓是一款专为古典诗词爱好者设计的FNOS版个人诗词管理工具。它既是一个私人诗库，也是一个创作辅助工具，帮助您录诗、整理、品评、
校验格律，所有数据存储在您自己的FNOS上，完全离线、完全私密。

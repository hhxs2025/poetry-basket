# 📜诗篓-Poetry Basket

> 个人诗词工作台 · 录诗 · 校验 · 整理 · 导出


## 应用简介

**诗篓** 是一款专为古典诗词爱好者设计的个人诗词管理工具。它既是一个个人诗库，也是一个创作辅助工具，帮助您录诗、整理、品评、校验格律，所有数据存储在您自己的 NAS 上，完全离线、完全私密。


## 核心功能【fnos用native版fpk-1.2.0】

| 功能 | 说明 |
|------|------|
| **📝 录诗** | 收录古人佳作或自己创作，支持题目、作者、朝代、体裁、笺注、赏析、主题等完整字段，系统自动记录录入人 |
| **🎋 格律校验** | 内置平水韵（精简版，含 100+ 韵部、2000+ 常用韵字），自动检测押韵与平仄，辅助诗词创作与修改 |
| **📚 诗库** | 所有用户共享诗库内容，按主题、作者、朝代分类聚合，支持搜索与筛选 |
| **🖼️ 配图** | 支持正文内插入图片（本站图片或外链），可指定宽度，图片保存于应用共享目录 |
| **📤 导出** | 支持单首或批量导出为纯文本，自动剥离排版标签，保留段落结构 |
| **👥 多用户** | 支持多用户登录，显示名称支持中文，管理员可管理用户及重置密码 |
| **🔒 数据安全** | 所有数据仅存储在 NAS 本地，不上传任何云端服务 |


## 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Python 3.11+ / Flask / Waitress |
| 韵书 | 内置《平水韵》精简版（100+ 韵部，2000+ 常用字），支持外部 JSON 扩展 |
| 数据库 | SQLite（单文件，易备份迁移） |
| 前端 | 原生 HTML / CSS / JavaScript（无重型依赖） |
| 部署 | 飞牛 FPK 原生应用 |


## 安装

在飞牛 NAS 应用中心搜索“诗篓”，点击安装即可。

如暂未上架应用中心，也可通过以下方式手动安装：

1. 在飞牛应用中心点击“手动安装”
2. 上传 `poetry-basket_1.2.0.fpk`
3. 阅读并同意安装须知
4. 完成安装后启动应用
5. 访问地址：`http://你的NAS_IP:5678`


## 数据存储

| 数据类型 | 存储位置 |
|---------|---------|
| 诗词库 | `/vol*/@appdata/poetry-basket/poetry.db` |
| 用户账号信息 | `app/data/users.json` |
| 扩展韵书 | `app/data/pingshui_ext.json`（可选） |
| 配图 | `/vol*/@appshare/poetry-basket/uploads/` |
| 应用日志 | `/vol*/@appdata/poetry-basket/info.log` |

> 备份时只需备份 `poetry.db`、`users.json` 和 `uploads/` 目录即可。
> 配图目录位于应用共享目录，可在飞牛「文件管理 → 应用文件」中直接查看和管理。

## 正文排版

正文支持 HTML 排版，常用写法如下：

| 需求 | 写法 |
|------|------|
| 居中 | `<div style="text-align:center">内容</div>` |
| 左对齐 | `<div style="text-align:left">内容</div>` |
| 右对齐 | `<div style="text-align:right">内容</div>` |
| 字号 | `<div style="font-size:1.2rem">内容</div>` |
| 加粗 | `<strong>文字</strong>` |
| 斜体 | `<em>文字</em>` |
| 引用 | `<blockquote>评语</blockquote>` |
| 分割线 | `<hr>` |
| 插图 | `<img src="/uploads/xxx.jpg" style="width:300px">` |
| 外链图 | `<img src="https://example.com/pic.jpg">` |

**示例**：

```html
<div style="text-align:center;font-size:1.2rem;line-height:1.8;">
空山新雨后，天气晚来秋。
明月松间照，清泉石上流。
</div>

<blockquote>王维此诗，诗中有画，画中有诗。</blockquote>
```

> 提示：`<div>` 内内容请顶格写，不要缩进，否则空格会显示出来。


## 扩展韵书

如内置韵书未覆盖某些生僻字，可在 `app/data/pingshui_ext.json` 中补充：

```json
{
  "鲲": {"tone": "平", "rhyme": "十三元"},
  "鹏": {"tone": "平", "rhyme": "十蒸"},
  "撼": {"tone": "仄", "rhyme": "二十七感"}
}
```

格式：`"汉字": {"tone": "平/仄", "rhyme": "韵部名称"}`


## 格律符号说明

| 符号 | 含义 |
|------|------|
| `—` | 平声 |
| `│` | 仄声 |
| `○` | 中（该字未收录于韵书，可平可仄） |

# 诗篓 Flex · 安卓客户端

## 一、项目简介

诗篓 Flex 是「诗篓」私人诗词工作台的安卓客户端**自由版**。与内置固定服务器地址的标准版不同，Flex 版允许用户自行填写服务端地址，服务器地址、登录账号与密码均可记住，适合自建服务端（飞牛 NAS、自有服务器、内网部署）的使用场景。

- 应用名称：诗篓 Flex
- 版本：2.0.0（versionCode 20000）
- 包名：`top.hhxs2025.shilou.flex`（与标准版不同，可同机共存）
- 运行环境：Android 5.0（API 21）及以上
- 配套服务端：诗篓服务端（Docker 镜像 / 飞牛 Docker 版 FPK）

## 二、核心功能

**可配置服务器**

- 登录页显示当前服务器地址，点击即可修改
- 登录后主界面菜单同样提供「服务器地址」入口，随时切换
- 保存后立即生效，并自动清理旧服务器的会话，避免串会话
- 支持 `http://` 与 `https://`，支持带端口（如 `http://192.168.1.10:8000`）

**记住登录**

- 「记住账号和密码」勾选框，勾选后下次打开自动预填
- 取消勾选则只记住账号（用于「只看我的」筛选），不保存密码

**与标准版共存**

- 包名独立，两个 APK 可同时安装在同一台手机上
- 桌面图标名称区分：诗篓 / 诗篓 Flex
- 标准版继续走云端更新通道，Flex 版跟随其连接的服务端更新通道，互不干扰

**诗词创作**

- 新建 / 编辑 / 删除诗词，支持标题、作者、正文、注释
- 正文配图：从相册选图上传，编辑页内插入
- 排版工具栏：对齐、分割线、插图、实时预览
- 详情页富文本渲染，图文混排正常显示

**检索与管理**

- 关键词搜索，作者与数量统计
- 长按进入多选模式，批量操作
- 「只看我的」本地筛选，只看自己录入的诗稿

**辅助能力**

- 格律校验：平仄、韵脚快速检查
- 导出所选诗词为 Markdown（系统「另存为」对话框，免存储权限）
- 导出自己的全部诗词数据为 SQLite db，便于迁移与备份
- 检查更新：走所连服务端的更新通道，下载后自动拉起安装
- 隐私政策、用户协议、关于我们

## 四、使用步骤

### 1. 安装

下载 `shilou-flex-2.0.0.apk`，传到手机安装。首次安装需允许「安装未知来源应用」。

> 与标准版包名不同，可同时安装，互不覆盖。

### 2. 填写服务器地址

打开应用，在登录页点击「服务器：xxx → 修改」，填写服务端地址：

| 场景        | 填写示例                           |
| --------- | ------------------------------ |
| 云服务器 + 域名 | `https://pb.hhxs2025.top`      |
| 飞牛 / 内网直连 | `http://192.168.1.10:8000`     |
| 带非标准端口的域名 | `https://pb.hhxs2026.top:8888` |

规则：以 `http://` 或 `https://` 开头，末尾不要带斜杠。保存后会提示「服务器已保存」。

### 3. 注册 / 登录

- 已有账号：填账号密码，勾选「记住账号和密码」，点登录
- 无账号：点「还没有账号？注册一个」，完成后返回登录

账号数据保存在服务端，换手机或重装 APP 后，只要服务器地址和账号一致即可登录，数据不丢。

### 4. 创作与管理

| 操作          | 入口                         |
| ----------- | -------------------------- |
| 新建诗词        | 右上角「新建」                    |
| 编辑 / 删除     | 进入详情页，右上角菜单                |
| 插入配图        | 编辑页工具栏「插图」                 |
| 排版          | 编辑页工具栏（对齐 / 分割线 / 预览）      |
| 搜索          | 主页搜索框 + 「搜索」按钮             |
| 只看自己的       | 右上角菜单 →「只看我的」              |
| 批量选择        | 长按任意一首诗                    |
| 导出 Markdown | 长按勾选后 → 菜单「导出所选为 Markdown」 |
| 导出个人 db     | 菜单「导出我的数据（db）」             |
| 格律校验        | 菜单「格律校验」                   |
| 检查更新        | 菜单「检查更新」                   |

### 5. 切换服务器

两种方式，效果一致：

1. 登录页点服务器地址行 → 修改 → 保存
2. 登录后主界面右上角菜单 →「服务器地址」→ 修改 → 保存

切换后会自动清空旧会话，需要用新服务器上的账号重新登录。已保存的账号密码不会被清除。

### 6. 关于更新

Flex 版的「检查更新」跟随**当前所连服务端**的版本配置：

- 连自建服务端 → 由该服务端后台「应用更新」决定推什么版本
- 连云端服务端 → 跟随云端发布节奏

因此两个渠道的版本号相互独立（Flex 用 2.x，标准版用 1.x），不会互相误推。

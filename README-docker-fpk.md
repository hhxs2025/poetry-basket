# 诗篓服务端 · Docker 版 FPK

## 一、项目简介

诗篓是一个私人诗词工作台，用于个人或小圈子记录、整理、检索原创诗词。「诗篓服务端」是整个系统的后端，提供数据存储、账号体系、配图上传、格律校验、数据导出与应用更新分发。

本项目把服务端封装成**飞牛 fnOS 的 Docker 版 FPK**，在飞牛应用中心一键安装即可运行，无需手敲 `docker run`，也不用自己维护 nginx 反代与端口映射。

- 应用形态：FPK（飞牛应用包，内含 Docker Compose 编排）
- 服务镜像：`ccr.ccs.tencentyun.com/hhxs2025/poetry-basket-server:1.0.0`
- 配套客户端：诗篓（标准版）/ 诗篓 Flex（自由版）

## 二、核心功能

**安装即用**

- 安装向导三步走：设置访问端口 → 设置后台密码 → 填写服务端访问地址
- 容器由飞牛应用中心托管，安装完成自动启动，桌面图标一点即开
- 端口可自定义，自动避开飞牛系统端口冲突

**数据安全**

- 数据全部持久化到飞牛「应用文件」目录下的 `poetry-basket` 子目录
- 容器重启、应用升级、重装系统均不影响数据
- 卸载向导可选「保留数据」或「彻底删除」，默认保留，防误删

**服务端能力**

- 诗词增删改查、关键词检索、作者与数量统计
- 多用户注册与登录、会话管理、后台管理密码保护
- 配图上传（正文插图）、富文本排版渲染
- 导出：所选诗词 Markdown、个人数据 SQLite db、全量备份与恢复
- 应用更新分发：上传 APK + 填写版本号 + 更新说明，客户端检查更新直链下载

**生命周期**

- 应用中心「启动 / 停止」状态联动，状态检测直读容器运行态
- 容器 `restart: unless-stopped`，NAS 重启后自动恢复
- 卸载前执行清理脚本，按用户选择决定是否清除数据

## 四、使用步骤

### 1. 安装

**方式 A：应用中心安装**  
下载 `诗篓服务端-1.0.0.fpk`，在飞牛「应用中心 → 手动安装」上传即可。

**方式 B：命令行安装（调试用）**

```bash
sudo appcenter-cli install-fpk /path/to/诗篓服务端-1.0.0.fpk
```

### 2. 完成安装向导

安装过程中会依次弹出三步配置：

| 步骤    | 填写内容             | 说明                                                    |
| ----- | ---------------- | ----------------------------------------------------- |
| 端口设置  | 应用访问端口，默认 `8000` | 8000 以上为宜，避开飞牛系统端口（80/443/5666/5667）                  |
| 密码设置  | 后台管理密码           | 用于登录 `/admin`，请牢记                                     |
| 服务端地址 | 对外访问地址           | 局域网：`http://NAS的IP:端口`；有域名：`https://你的域名`。**末尾不要带斜杠** |

`服务端地址` 决定图片链接与 APP 更新直链的生成前缀，填错会出现图片裂图、APP 下载更新失败。

### 3. 访问服务

- 桌面点击「诗篓」图标，或浏览器打开 `http://NAS的IP:端口`
- 管理后台：`http://NAS的IP:端口/admin`，用向导里设置的管理密码登录

### 4. 连接客户端

安装「诗篓」或「诗篓 Flex」安卓客户端：

- 标准版：服务器地址已内置，直接注册/登录
- Flex 版：首次进入在登录页填写服务器地址（如 `http://192.168.1.10:8000`），可勾选「记住账号和密码」

### 5. 日常维护

| 操作        | 位置                                                 |
| --------- | -------------------------------------------------- |
| 查看运行状态    | 应用中心应用卡片（运行中 / 已停止）                                |
| 启动 / 停止   | 应用中心对应按钮                                           |
| 修改端口或地址   | 目前需卸载重装（向导只在安装时执行），重装时选「保留数据」                      |
| 数据备份      | 管理后台「数据备份与恢复」面板，或直接拷贝 `应用文件/poetry-basket/backups` |
| 查看 / 迁移数据 | 文件管理器「应用文件」→ `poetry-basket` 目录                    |

### 6. 升级

新版本发布后，在应用中心卸载旧版并安装新 FPK，卸载时选择**保留数据**，重装后数据与账号自动接续。

### 7. 卸载

应用中心卸载时会弹出向导：

- **保留数据**（推荐）：仅移除应用与容器，`应用文件/poetry-basket` 内的诗词、账号、配图、备份全部保留，重装即恢复
- **彻底删除所有数据**：连同数据库与配图一并清空，**不可恢复**
